# Rime 输入方案：五笔98·拼音 · 粤拼 · 拼音

一套自用的 Rime（小狼毫）输入法配置，含三种方案，支持 Emoji 表情符与简繁切换。

## 包含的方案

| 方案 | schema_id | 说明 |
|---|---|---|
| 五笔98·拼音 | `wubi98_pinyin` | 王码五笔98版，五笔 + 拼音混合输入 |
| 拼音 | `pinyin_simp` | 全拼 + 简拼 |
| 粤拼 | `jyut6ping` | 粤语拼音，支持调号数字输入（ngo5=我） |

**所有方案**：简体默认，可切换**香港繁体 / 台湾繁体**；带 **Emoji 表情符**（打"笑"出 😄，"吉他"出 🎸 等）。

## 安装方法

1. 安装小狼毫 Weasel（Windows）或任意 Rime 前端
2. 将本仓库**所有文件**复制到 Rime 用户目录：
   - Windows 默认：`%APPDATA%\Rime`（即 `C:\Users\你的用户名\AppData\Roaming\Rime`）
   - 若用户目录在别处，改注册表 `HKCU\Software\Rime\Weasel` 的 `RimeUserDir`
3. 托盘右键 → **重新部署**
4. `Ctrl+` 切换方案；`Shift` 切换中英文

## 使用要点

- **词频记忆已开启**：常用字/词多打几次会自动前置
- **表情符**：默认开启，打表情关键词候选里会带 Emoji
- **繁简切换**：切到"香港繁體/臺灣繁體"输出繁体
- **五笔98打不出某个字**：可打该字的拼音（五笔拼音混合方案支持）

## 词库来源

- 五笔98：王码98版单字/词组；单字已按《通用规范汉字表》8105字补齐
- 拼音：mozillazg/pinyin-data、phrase-pinyin-data 等开源数据
- 粤拼：rime-cantonese（简体化处理）
- 表情：rime-emoji + 自定义扩充（礼物、乐器、花朵等）
